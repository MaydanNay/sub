NGROK (Mini App в Telegram)
---------------------------
1. ngrok http 5173          ← один туннель на mini-app
2. WEBAPP_URL = этот URL в .env + BotFather
3. mini-app/.env — VITE_API_URL оставить пустым (API идёт через proxy)
4. npm run dev — перезапустить после смены .env

ПРИМЕЧАНИЕ
----------
Mini App в Telegram требует HTTPS (ngrok / cloudflare tunnel).
В .env обязательно TELEGRAM_BOT_TOKEN — без него Mini App не авторизует.
После смены ngrok-URL: обновить WEBAPP_URL и BotFather, перезапустить npm run dev.

ПЕРСОНАЖ MINI APP
-----------------
Менять файл: mini-app/src/assets/pers.png  (НЕ dist/ — он пересобирается)
После замены — обновить Mini App в Telegram (жёсткое обновление).
