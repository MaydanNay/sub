## 3. Интеграции с существующими платформами

SHŪ School работает в партнёрстве с существующими системами. Мы **не конкурируем** — мы дополняем.

### 3.1 Kundelik.kz (основная интеграция для Казахстана)

**Что Kundelik делает:**
- Электронный журнал и дневник
- Расписание уроков
- Выставление оценок учителями
- Домашние задания
- Посещаемость (отмечается учителем)
- Общение родителей и учителей
- 6 000+ школ, 325 000+ учителей в Казахстане

**Что SHŪ School берёт из Kundelik (через API или ручной импорт):**
- Оценки ученика по предметам → конвертируются в игровые статы
- Домашнее задание → передаётся на AI-декомпозицию
- Список предметов школы → маппинг на характеристики персонажа

**Что SHŪ School НЕ делает:**
- Не выставляет оценки
- Не заменяет журнал
- Не изменяет расписание

**Формат интеграции:** REST API (при наличии у Kundelik публичного API) или CSV/Excel импорт данных как fallback.

### 3.2 EduPage

**Что EduPage делает:**
- Расписание и тарификация
- Электронный классный журнал
- Посещаемость (вход учителя в мобильном приложении)
- Система контроля входа в школу
- Обмен сообщениями

**Что SHŪ School берёт из EduPage:**
- Данные об оценках и домашних заданиях → игровая конвертация
- Список предметов → маппинг на статы

**Формат интеграции:** EduPage API (доступен для партнёров) или ручной синк.

### 3.3 Независимый режим

Для образовательных центров, не использующих Kundelik или EduPage, SHŪ School работает **автономно**: учитель вручную задаёт ДЗ и оценки внутри нашего приложения.

## 4. Функциональные требования

### 4.1 Модуль посещаемости — Вход в здание

**Описание:**  
На ресепшене школы/образовательного центра размещается экран с QR-кодом. QR-код динамически обновляется каждые **N минут** (значение настраивается администратором, рекомендуется 5 минут). Ученик при входе открывает приложение, сканирует QR — система фиксирует:
- Факт прихода
- Время прихода
- Статус: **вовремя** / **опоздание** (сравнивается с расписанием из системы)

**Поведение системы:**
- Если ученик пришёл вовремя → +X коинов, +1 к стрику «Без опозданий»
- Если опоздал → 0 коинов, сброс стрика, фиксация в аналитике
- Если не пришёл совсем → отметка «Отсутствие» (берётся из Kundelik/EduPage или фиксируется вручную)

**Экран ресепшн:**
- Только QR-код и название школы/центра
- Автообновление без перезагрузки страницы
- Работает как веб-страница на планшете/мониторе

**Роли:**
- Администратор настраивает время начала занятий (привязка к расписанию)
- Ученик сканирует своим устройством

---

### 4.2 Модуль посещаемости — Уроки

**Описание:**  
У каждого учителя есть персональный QR-код занятия. В начале урока учитель показывает QR ученикам (на экране или в приложении). Ученики сканируют — фиксируется посещение конкретного занятия.

**Поведение системы:**
- Ученик сканировал QR урока в окне ±5 минут от старта → присутствовал, +X коинов
- Не сканировал → пропустил занятие
- Данные синхронизируются с журналом посещаемости (Kundelik / EduPage / внутренний журнал)

**Интерфейс учителя:**
- Кнопка «Начать урок» → генерирует QR на N минут
- Просмотр, кто из учеников уже отметился в реальном времени
- Возможность вручную отметить ученика (если телефон разряжен и пр.)

---

### 4.3 Геймификация домашних заданий

**Описание:**  
Учитель задаёт домашнее задание (текстом, через наше приложение или через импорт из Kundelik/EduPage). ИИ-модуль анализирует задание и автоматически разбивает его на **подзадачи (шаги)**.

**Логика ИИ-декомпозиции:**
- Если ДЗ = список упражнений → каждое упражнение = отдельный шаг
- Если ДЗ = сложная задача (эссе, проект, задача с доказательством) → ИИ сам определяет логические микрошаги (план → черновик → итог / условие → схема → решение → проверка)
- Количество шагов: 2–7 на одно ДЗ
- Каждый шаг = фиксированное количество коинов (настраивается)

**Виды заданий:**
| Тип | Описание | Награда |
|---|---|---|
| Обычное ДЗ | Стандартное домашнее задание | Обычные коины за каждый шаг |
| ДЗ со звёздочкой ⭐ | Задание повышенной сложности | **Суперкоины** — более редкая валюта |

**Подтверждение выполнения:**
- Ученик отмечает каждый шаг как выполненный внутри приложения
- Учитель подтверждает выполнение (через проверку на следующем уроке или через наше приложение)
- Только после подтверждения учителя коины зачисляются окончательно
- Предусмотреть: ученик загружает фото/файл ДЗ как подтверждение (опционально, MVP v2)

### 4.4 Игровая валюта

**Два типа валюты:**

| Валюта | Как получить | Назначение |
|---|---|---|
| **Коины** 🪙 | Вход вовремя, посещение урока, выполнение шага ДЗ | Основная валюта развития персонажа/цивилизации |
| **Суперкоины** ⭐ | ДЗ со звёздочкой, особые достижения, редкие события | Разблокировка редких предметов/бонусов |

**Таблица начисления (примерная, настраивается администратором):**

| Действие | Коины | Суперкоины |
|---|---|---|
| Вход без опоздания | +5 | — |
| Посещение урока | +3 | — |
| Выполнение шага обычного ДЗ | +2 | — |
| Выполнение всего обычного ДЗ | +5 (бонус) | — |
| Шаг ДЗ со звёздочкой | — | +1 |
| Стрик без опозданий (7 дней) | +25 | +1 |
| Стрик выполнения ДЗ (5 дней подряд) | +20 | — |

**Штрафы:**

| Событие | Эффект |
|---|---|
| Опоздание | Сброс стрика «Без опозданий» |
| Плохое поведение (учитель фиксирует) | -N коинов (настраивается) |
| Пропуск урока | 0 коинов за урок, фиксация в аналитике |

### 4.5 Система стриков

**Стрики — один из ключевых мотиваторов.** Каждый стрик видит сам ученик. Маскот напоминает о стриках.

| Стрик | Условие | Сброс |
|---|---|---|
| 🔥 Без опозданий | N дней подряд без опоздания | Любое опоздание |
| 📚 Домашний герой | N дней подряд сдано ДЗ вовремя | Пропуск сдачи ДЗ |
| ✅ Стопроцентник | N уроков подряд без пропусков | Пропуск занятия |
| 🌟 Звёздный ученик | N ДЗ со звёздочкой подряд | Пропуск выполнения звёздного ДЗ |

**UX-логика стриков:**
- При входе в приложение ученик видит статус своих стриков
- Маскот говорит: «Ты уже 6 дней без опозданий! Ещё один день — и ты получишь 25 коинов!»
- При угрозе сброса стрика (например, сегодня последний день) — пуш-уведомление утром

### 4.6 Игровой персонаж / Цивилизация

> ⚠️ **Открытый вопрос — обсудить с разработчиком на созвоне**
>
> Два варианта игрового прогресса:
>
> **Вариант А — Персонаж (RPG-стиль)**  
> Ученик развивает своего героя: растёт уровень, появляются новые способности, предметы, внешний вид.
>
> **Вариант Б — Цивилизация (стратегия-стиль)**  
> Ученик строит и развивает свой город/королевство. Здания, ресурсы, население.
>
> **Какой вариант выбрать — зависит от:**
> - Возраста целевой аудитории (персонаж лучше для 7–12 лет, цивилизация — для 12–18)
> - Технических возможностей (цивилизация сложнее в реализации)
> - Тестирования с детьми

#### 4.6.1 Маппинг предметов на характеристики

Каждый школьный предмет влияет на определённую характеристику персонажа или ресурс цивилизации.

**Важно:** все характеристики должны быть **одинаково необходимы**. Нельзя «забить» на один ресурс и выиграть за счёт другого. Это стимулирует равномерно развиваться по всем предметам.

**Пример маппинга (персонаж):**

| Предмет | Характеристика | Почему |
|---|---|---|
| Математика | 💰 Экономика / Богатство | Логика, счёт, управление ресурсами |
| Литература / Русский | 📖 Мудрость | Понимание смыслов, риторика |
| История | 🏛️ Влияние / Политика | Знание прошлого, стратегия |
| Биология / Химия | ❤️ Здоровье / Жизненная сила | Понимание природы и тела |
| Физкультура | ⚔️ Сила / Выносливость | Прямая связь |
| Английский | 🌍 Связи / Дипломатия | Коммуникация с миром |
| Физика | ⚙️ Технологии / Изобретения | Законы природы и механики |
| Информатика | 🤖 Интеллект / Автоматизация | Цифровые навыки |

**Пример маппинга (цивилизация):**

| Предмет | Ресурс | Описание |
|---|---|---|
| Математика | 💰 Золото | Казна цивилизации |
| Биология | 🌾 Еда | Пропитание населения |
| Физика | ⚙️ Производство | Фабрики и механизмы |
| История | 👑 Слава | Репутация в мире |
| Английский | 🤝 Дипломатия | Союзники и торговля |
| Физкультура | 🛡️ Армия | Защитная мощь |
| Информатика | 🔬 Наука | Исследования |

**Баланс ресурсов:**
- Все ресурсы расходуются при развитии (строительство зданий, апгрейд, события)
- Если один ресурс на нуле — определённые функции цивилизации/персонажа недоступны
- Система сама предупреждает: «Твоя армия слабеет — займись физкультурой!»

#### 4.6.2 Как считается прирост характеристики

- Берётся текущая оценка ученика по предмету (из Kundelik/EduPage или внутреннего журнала)
- Берётся активность: сколько ДЗ сдал, как посещал уроки по этому предмету
- Результирующий коэффициент = (средняя оценка × 0.6) + (посещаемость × 0.25) + (активность ДЗ × 0.15)
- Коэффициент определяет, насколько быстро растёт соответствующая характеристика

> Конкретные формулы и веса согласовать с разработчиком при балансировке.

### 4.7 Модуль поведения (Учитель → Ученик)

**Описание:**  
Учитель может зафиксировать нарушение поведения прямо в приложении. Не через электронный дневник — а именно в нашей системе.

**Сценарий использования:**
1. На уроке или вне урока ученик нарушает правила
2. Учитель открывает приложение → находит класс и ученика
3. Выбирает тип нарушения из списка (преднастроен администратором)
4. Подтверждает → в профиле ученика фиксируется штраф

**Типы нарушений (настраиваются):**
- Опоздание на урок (если не через QR — дополнительная фиксация)
- Нарушение дисциплины на уроке
- Использование телефона
- Хулиганство / конфликт
- Нарушение дресс-кода
- и пр.

**Штраф:**
- Каждому типу нарушения администратор задаёт вес (-N коинов)
- Штраф виден ученику в профиле с объяснением причины 
- Учитель может добавить короткий комментарий

**Важно:**
- Ученик видит, за что он получил штраф (прозрачность)
- Родитель (MVP v2) получает уведомление
- Хранится история нарушений — помогает видеть паттерны

### 4.8 Аналитика и профиль ученика

**Профиль ученика содержит:**
- Текущий уровень персонажа/цивилизации
- Общий счёт коинов (обычных и суперкоинов)
- Активные стрики и их история
- Радарная/паутинная диаграмма всех характеристик (чтобы сразу видеть «западающие» предметы)

**Аналитика по предметам:**
- Ученик может зайти в любой предмет и увидеть:
  - Среднюю оценку за период
  - % сданных ДЗ
  - % посещённых уроков
  - Как эта статистика влияет на конкретную характеристику персонажа

**Общий индекс:**
- Автоматически вычисляется «общий индекс успеваемости» как взвешенная сумма всех характеристик
- Этот индекс — визуальный, игровой. Не дублирует официальный средний балл.

**Интерфейс аналитики:**
- Главный экран: персонаж + паутинная диаграмма + топ-3 проблемных предметов
- Детальный экран предмета: графики по времени, история оценок, ДЗ
- Вкладка «Стрики»: все активные и прошлые стрики

### 4.9 AI-Маскот (Сопровождающий персонаж)

**Описание:**  
Маскот — это постоянный компаньон ученика в приложении. ИИ-персонаж, который «следит» за прогрессом, замечает проблемы и поддерживает.

**Внешний вид:**
- Небольшой анимированный персонаж (связан тематически с игровым миром)
- Есть несколько эмоциональных состояний: радостный, обеспокоенный, удивлённый, гордый
- Появляется как уведомление или как персонаж на главном экране

**Функции маскота:**

| Триггер | Что говорит маскот |
|---|---|
| Ежедневный вход | Приветствие + напоминание о сегодняшних задачах |
| Невыполненное ДЗ | «Эй, у тебя ещё не закрыто домашнее по математике! Хочешь начнём?» |
| Западающий предмет | «Замечаю, что биология у тебя просела. Всё нормально? Есть сложности с ДЗ?» |
| Угроза стрику | «Осторожно! Твой стрик 6 дней подряд без опозданий под угрозой. Не забудь прийти вовремя завтра!» |
| Штраф от учителя | «Получил замечание сегодня. Всё ок? Если что-то случилось — попробуй поговорить с учителем» |
| Достижение стрика | «ВАУ! 7 дней без опозданий! Ты просто огонь 🔥 Вот тебе 25 коинов!» |
| Долго не заходил | «Привет! Скучал по тебе. Пока тебя не было, твоя цивилизация немного застыла...» |

**Диалоговые сценарии (check-in):**

Маскот периодически инициирует короткий диалог:
- «Как дела с ДЗ по физике? Понятно всё?»
  - → «Всё норм» / «Есть сложности»
  - Если «Есть сложности» → «Хочешь я разобью задание на шаги?» / «Попроси учителя объяснить снова»

**Технология маскота:**
- Базовые сообщения: шаблонные фразы с подстановкой данных (имя, предмет, стрик)
- Умный режим: LLM (например, GPT-4o mini) генерирует персонализированный ответ на основе профиля ученика
- Маскот НЕ даёт ответы на ДЗ — только мотивирует и направляет

## 6. Нефункциональные требования

- **Безопасность:** данные учеников — персональные данные несовершеннолетних. Соответствие казахстанскому законодательству о персональных данных (Закон РК «О персональных данных»). Шифрование в транзите (HTTPS) и хранении.
- **Производительность:** QR-сканирование → ответ системы ≤ 1 секунда
- **Офлайн-режим:** базовый просмотр профиля и ДЗ без интернета. Синхронизация при восстановлении соединения.
- **Поддержка устройств:** iOS 15+, Android 10+. Планшет для экрана ресепшн.
- **Языки:** казахский, русский (переключение)
- **Тёмная/светлая тема**
